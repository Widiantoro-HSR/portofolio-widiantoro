# Portofolio Widiantoro Harya S.R.

Website portofolio mahasiswa D3 Teknik Komputer Politeknik Negeri Samarinda. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework agar mudah diedit dan dipublikasikan lewat GitHub Pages.

## Isi website

- Profil singkat
- Keterampilan pemrograman, embedded system/IoT, basis data, dan produktivitas
- Tiga proyek tugas kuliah: pengelolaan data mahasiswa (C++), penghitung nilai (MATLAB GUI), dan monitoring suhu (Arduino Uno + LM35)
- Pengalaman PKL dan kegiatan pembelajaran C++
- Email serta tautan folder Google Drive

## Cara melihat secara lokal

1. Unduh atau ekstrak semua file ke satu folder.
2. Buka `index.html` dengan browser.
3. Untuk mengubah konten, edit `index.html`; tampilan diatur dalam `style.css`, dan menu ponsel diatur dalam `script.js`.

## Cara mengunggah ke GitHub

1. Masuk ke GitHub dan buat repository baru, misalnya `portofolio-widiantoro`.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke bagian paling atas (root) repository.
3. Buka **Settings → Pages**.
4. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses publikasi selesai. Alamat website akan terlihat pada halaman GitHub Pages di pengaturan repository.

Dokumentasi resmi: https://docs.github.com/en/pages/quickstart

## Sebelum dipublikasikan

Periksa kembali alamat email dan tautan Google Drive. Website GitHub Pages yang dipublikasikan dapat diakses orang lain. Nomor WhatsApp dan NIM tidak ditampilkan pada website ini untuk mengurangi paparan informasi pribadi.
